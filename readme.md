# REST API Based To-Do Application

## Overview
A modern, responsive To-Do application built with vanilla JavaScript that communicates with a REST API endpoint for data retrieval, featuring complete task management (CRUD operations, filtering, and responsive design).

## Features
- **REST API Integration:** Fetches initial tasks dynamically using the Fetch API (`JSONPlaceholder`).
- **Interactive State Management:** Add, complete, and delete tasks seamlessly.
- **Task Filtering:** Filter tasks instantly by All, Active, or Completed status.
- **Responsive Design:** Clean, card-based modern UI that adapts to mobile and desktop screens.

## Tech Stack
- HTML5, CSS3 (Flexbox, CSS Variables), JavaScript (ES6+, Fetch API)
- FontAwesome Icons
